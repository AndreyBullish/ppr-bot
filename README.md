# Бот напоминаний ППР — Сколтех

Telegram-бот, который каждый **понедельник в 09:00 МСК** отправляет напоминание о системах, требующих **ТО-3** и **ТО-4** в текущем месяце.

---

## Деплой на Railway (бесплатно)

### Шаг 1 — Создайте аккаунт
Зайдите на [railway.app](https://railway.app) и войдите через GitHub.

### Шаг 2 — Создайте новый проект
- Нажмите **New Project**
- Выберите **Deploy from GitHub repo**
- Загрузите эти файлы в репозиторий GitHub (или используйте **Deploy from local** если Railway предложит)

### Шаг 3 — Добавьте переменные окружения
В настройках сервиса (Variables) добавьте:
```
BOT_TOKEN = 8807180333:AAETatngFRmz5WogYXyuTN2oFequeALPbJs
CHAT_ID   = 5759230833
```

### Шаг 4 — Задеплойте
Railway автоматически установит зависимости из `requirements.txt` и запустит `Procfile`.

---

## Что умеет бот

- Каждый понедельник присылает список систем для ТО-3 и ТО-4 текущего месяца
- При запуске отправляет подтверждение что бот работает
- Данные взяты из годового графика ППР Сколтеха 2026

## Структура файлов
